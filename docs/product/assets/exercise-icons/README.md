# 운동 검색 아이콘 v0.9

[HTML 와이어프레임](../../Overload_UI_Baseline_Wireframe_v0.9.html)의 `v9Icons`에 내장된 원본 PNG를 바이트 변경 없이 추출했습니다.

- 가슴: `chest.png` / 등: `back.png` / 하체: `legs.png`
- 러닝: `running.png` / 걷기: `walking.png` / 사이클(자전거): `cycling.png`
- 설정 카탈로그 행에 추가 적용한 분류는 어깨(`shoulders.png`), 팔(`arms.png`), 코어(`core.png`)입니다. 유산소는 HTML과 동일한 `walking.png`를 재사용하며, 기타는 중립적인 `ETC`로 표시합니다.
- 원본: 128×128 PNG. 실제 UI에서는 32 CSS px로 표시하며 원본을 축소·재인코딩하지 않습니다.
- 원본 품질·투명도·중립 그레이 배경을 보존합니다. 파스텔 배경이나 임의의 방향 화살표를 추가하지 않습니다.
- 파일 크기·SHA-256·원본 키는 [manifest.json](manifest.json)에 기록했습니다.
- [추출 미리보기](Overload_Icons_v0.9_Extracted_Preview.png)에는 초기 6종이 담겨 있습니다.
- 색상·배경·표시 기준은 [Visual Theme Spec](../../Overload_UI_Visual_Theme_Spec_v0.9.md)을 따릅니다.
