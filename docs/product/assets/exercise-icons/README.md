# 운동 검색 아이콘 v0.9

[HTML 와이어프레임](../../Overload_UI_Baseline_Wireframe_v0.9.html)의 `v9Icons`에 내장된 원본 PNG 6종을 바이트 변경 없이 추출했습니다.

- 가슴: `chest.png` / 등: `back.png` / 하체: `legs.png`
- 러닝: `running.png` / 걷기: `walking.png` / 사이클(자전거): `cycling.png`
- 원본: 128×128 PNG. 실제 UI에서는 32 CSS px로 표시하며 원본을 축소·재인코딩하지 않습니다.
- 원본 품질·투명도·중립 그레이 배경을 보존합니다. 파스텔 배경이나 임의의 방향 화살표를 추가하지 않습니다.
- 파일 크기·SHA-256·원본 키는 [manifest.json](manifest.json)에 기록했습니다.
- 제공된 [추출 미리보기](Overload_Icons_v0.9_Extracted_Preview.png)는 검토용이며 실제 아이콘 대신 사용하지 않습니다.
- 색상·배경·표시 기준은 [Visual Theme Spec](../../Overload_UI_Visual_Theme_Spec_v0.9.md)을 따릅니다. 운영 PWA에 적용 완료되었다는 의미는 아닙니다.
