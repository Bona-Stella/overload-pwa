# Overload UI v0.9 — Visual Theme Specification

**기준일:** 2026-11-05

**범위:** React PWA 실제 구현용 시각 스타일 명세. [Overload_UI_Baseline_Wireframe_v0.9.html](Overload_UI_Baseline_Wireframe_v0.9.html)은 흑백 저충실도 UX 와이어프레임이므로 **아래 색상을 적용하지 않는다.**

**기술 방향:** CSS Custom Properties + CSS Modules, 모드에 따라 `data-theme` 토큰만 변경. 테마 변경으로 데이터/타이머/입력값을 초기화하지 않는다.

## 1. 공통 Onyx와 강조색

| 역할 | 일반 / 디로딩 공통·변화 |
|---|---|
| 앱 페이지 바탕 | `#111216` (공통) |
| 기본 카드 바탕 | `#1B1D22` (공통) |
| 내부·입력 바탕 | `#25282E` (공통) |
| 주요 본문 | `#F0F1F4` (권장, 공통) |
| 보조 본문 | `#A9ADB7` (권장, 공통) |
| 일반 모드 주 강조 | Dusty Blue `#6C93C6` |
| 디로딩 모드 주 강조 | Mint Sage `#78B89A` |
| 주요 CTA 위 글자 | 어두운 `#111820` (대비 점검) |

기본 배경·일반 카드·입력은 두 모드에서 같다. 페이지 전체를 파랗거나 초록빛으로 바꾸지 않는다. `WEIGHT`, `CARDIO`, 운동 시작 CTA, 선택 상태·오늘 날짜, 활성 탭에 해당 모드 강조색을 적용한다. 일반 운동명·중량/세트 텍스트는 모드 색으로 통째로 물들이지 않는다.

## 2. 강조 카드의 저채도 그라데이션

**일반 모드** (왼쪽 상단 → 오른쪽 하단 같은 블루그레이 계열):

```css
linear-gradient(142deg, #272D37 0%, #222832 50%, #1C212A 100%);
```

테두리 참고 `#3B4453`.

**디로딩 모드** (아래 끝까지 같은 그린그레이 계열):

```css
linear-gradient(142deg, #28312C 0%, #222B26 50%, #1A231E 100%);
```

테두리 참고 `#3B4A40`.

그라데이션은 **오늘의 루틴 등 중요한 강조 카드**에만 적용한다. 일반 보조 카드·주간 일정은 공통 Onyx 카드에 둔다. 오른쪽 아래를 중립 회색으로 되돌리는 이전 디자인은 폐기한다.

## 3. 상태색과 게이지

- 과거 계획 운동 완료 ✓: `#74A68A` (어두운 초록)
- 과거 계획 운동 미수행 ×: `#B17B83` (어두운 빨강)
- 과거 휴식일 `-`: 중립 보조색. 요일 대신 나타나지만 완료 의미가 아니다.
- 세트 완료 원형 체크: 위 완료색 계열을 이용한 얇은 초록 체크와 둥근 테두리. **행 전체를 초록으로 채우지 않음.** 일반과 디로딩에서 동일 규칙. 완전 취소/정정 API 정책과 구분.
- 오늘 및 미래 일정의 요일은 그대로 유지. 과거 날짜 숫자·루틴명만 어둡게. 상위 `opacity`로 ✓와 ×를 탈색시키지 말 것.

**분석 ON 추천 게이지:** 0주부터 항상 가는 수평 트랙을 표시하며 채움 길이는 `clamp(weeks / 8, 0, 1)`. 0~4.0주(포함) Dusty Blue `#6C93C6`, 4.0주 초과는 황→주황→적의 점진 보간. 8주 이상 100% 빨강. 분석 OFF일 땐 게이지 숨김.

| 기준 예시 | 색상 후보 |
|---|---|
| 4.0주 이하 | `#6C93C6` **확정** |
| 4.0주 초과 경고 시작 | `#D6BC65` (후보) |
| 6.0주 | `#D98D55` (후보) |
| 8.0주 | `#C96763` (후보) |

4.0주에서 4.0주를 아주 조금 넘는 순간은 의도적으로 카테고리가 바뀐다. 색 외에도 `n.n/8주` 수치를 유지한다. 경고 세 색의 정확한 HEX는 시안 후보로 취급하고 개발에서 공통 토큰에 집중 관리한다.

## 4. 텍스트 위계 — 중량과 장비

| 콘텐츠 | 권장 표현 및 우선순위 |
|---|---|
| 세트당 **실제 수행 중량 × 반복 횟수** | **밝은 본문** `#F0F1F4`, 12~13px 수준, 600~700 weight; 읽히는 것이 최우선 |
| 세트 오른쪽 **볼륨(kg)** | 일반 본문/보조 사이의 충분한 대비, 축소·투명도 과도 적용 금지 |
| 종목명·세트 수 | 상단 주요 텍스트, 명확한 대비 |
| **제조사·부하 방식·당시 기록** | **작은 보조 글자** 10~11px, normal 400, `#A9ADB7` 또는 한 단계 낮은 중립색, 전 화면 일관 적용. 흰색/굵은 대제목 금지 |
| 레이블 `WEIGHT` · `CARDIO` | 해당 모드 주 강조색을 유지 |
| 물음표 도움말 | 원형 **시각 지름 약 16px**(기존 23px보다 작게), 본문과 균형. **실제 터치 대상은 44×44 CSS px에 가까운 히트영역**으로 보완(선택 UI의 터치 접근성 유지) |

대상 화면: 운동 완료 요약, 기록 상세, 운동 진행 포커스, 임시 편집/장비 선택, 운동별/제조사별 통계, 복구/정정 맥락 등 **장비 메타데이터가 등장하는 전체 화면**. 수정 가능한 입력 필드의 기본 접근성과 구별한다.

## 5. 세트 완료 컨트롤

- 진행 전: `완료` 버튼 + 반복수 입력과 `− / +` 제공.
- 완료 후: 행 전체에 배경색을 채우지 않음. 버튼 위치에 **원형 테두리 ✓**를 표시하고 `−/+` 및 수치 입력을 표시하지 않는다(값은 읽기 텍스트로 표시).
- 체크 탭: 「완료를 취소하시겠습니까?」 팝업 (`아니요 · 유지` / `완료 취소`). 후자를 선택했을 때만 입력과 `완료` 버튼 복귀. 실제 서버 삭제·정정/오프라인 원본 처리 정책을 준수.

## 6. 구현·검증 지침

- 32px 검색/운동 선택 아이콘은 [아이콘 자산](assets/exercise-icons/README.md)의 기존 원본 PNG를 표시한다. 원본 이미지를 32 CSS px로 렌더링하며 중립 그레이/Onyx 배경, 별도의 파스텔 컬러 원형 배경 금지.
- `data-theme`은 화면 표시 스타일만 바꾸며 서버의 실제 디로딩 상태/쓰기 권한과 동치가 아니다. 일반 보기 읽기 전용 정책 유지.
- 앱의 CSS 토큰 예시:

```css
:root {
  --surface-page: #111216;
  --surface-card: #1B1D22;
  --surface-input: #25282E;
  --text-primary: #F0F1F4;
  --text-muted: #A9ADB7;
  --accent: #6C93C6;
  --on-accent: #111820;
  --status-done: #74A68A;
  --status-missed: #B17B83;
  --hero-gradient: linear-gradient(142deg, #272D37 0%, #222832 50%, #1C212A 100%);
}
[data-theme="deload"] {
  --accent: #78B89A;
  --hero-gradient: linear-gradient(142deg, #28312C 0%, #222B26 50%, #1A231E 100%);
}
```

- WCAG 대비 검토, iPhone 15 Safari 및 홈화면 PWA 실제 렌더링, 재마운트/타이머 리셋 방지, 아이콘 이미지 자산 경로와 캐시 검증은 React 통합 단계에서 수행.
- HTML은 **흑백 UI 플로우 시뮬레이션**에 집중하고 위 시각 테마는 CSS Modules 실제 구현 단계에서만 적용한다. [Overload_UI_Decision_Log_v0.9.md](Overload_UI_Decision_Log_v0.9.md)는 사용자 행동/배치·정보 위계·정책, [Overload_Deloading_Design_Specification_v1.6.md](Overload_Deloading_Design_Specification_v1.6.md)는 디로딩 제품 계약을 책임진다.
