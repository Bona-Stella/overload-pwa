# FRONT 18 — 6-A 드롭다운·검색·필터·액션 메뉴 공통화

사용자 재검수 및 최종 승인 대기

[6-1 조사](front-18-6-1-dropdown-audit.md) · [92개 적용 현황](evidence/front-18-6-a/rollout-inventory.md)

- `ConnectedDropdown`은 연결형 선택·홈 콘텐츠, 독립형 필터·검색 범위·액션 메뉴의 방향, 내부 스크롤, 키보드 조작과 닫힘 처리를 공유한다. 선택 배경은 현재값에서 유지한다. 키보드 탐색에는 기존 포커스 테두리를 사용한다.
- 요일별 루틴, 제조사와 부하 방식은 검색창 없는 `SelectDropdown`을 사용한다. 배정 초안, 후보 필터, 장비의 미지정과 현재값은 호출부가 관리한다.
- 홈의 임시 루틴 선택은 기존 정보 순서와 목록형 행을 사용한다. 홈과 종목 검색의 필터는 공통 태그의 36px 시각 영역과 44px 이상 터치 영역을 공유한다. 종목 추가·변경에서는 웨이트 목록을 검색 입력과 함께 연다.
- `SearchList`는 종목 검색, 기존 상세 버튼과 결과·오류 상태를 지원한다. 주간 일정·루틴 카드·운동 기록의 메뉴는 `ActionMenu`로 기존 활성 조건과 확인 절차를 실행한다.
- 6-4에서 남은 사용처를 대조한다. 유산소 운동 중 계획 설정과 완료 기록 디자인은 후속 범위다.
