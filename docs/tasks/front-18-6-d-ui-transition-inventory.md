# FRONT 18 · 6-D 전체 UI 상태 전환 현황표

2026-11-27 · Frontend `545b711` · Backend `5a12b1c` · [통합 분석](front-18-6-d-ui-transition-audit.md)

번호는 사용자 동작 또는 시스템 이벤트로 구분한 전환이다. S01~S46은 공통 셸·진입, 운영 페이지, 독립적으로 조작하는 하위 흐름의 단위다. 반복되는 카드·세트·목록 행은 같은 상태 전환을 공유하면 한 번만 센다. 6-B의 정적 표현 177행과 집계 단위가 다르다. [6-B 현황표](front-18-6-b-ui-inventory.md)

A 정상 · B 불필요한 중간 UI · C 위치·크기 변화 · D 전환·마운트 구조 · E 조회·비동기 갱신 · F 저장·복구 노출 · G 필요한 변화 · H 재현·확인이 필요한 전환. 행마다 주된 분류 하나를 표시한다. R1~R6은 [통합 분석의 공통 원인](front-18-6-d-ui-transition-audit.md#원인과-영향)을 가리킨다.

- **실제**는 4174 검수 앱과 전용 Spring 계정의 Chrome 실행이다. **실제·주입**은 이 앱에서 읽기 응답만 지연하거나 일시 오류로 바꾼 경우다.
- **격리**는 현재 소스와 기존 React 브라우저 fixture다. **Preview**는 4174의 별도 합성 컴포넌트 페이지다.
- **소스**는 조건과 호출 경로를 확인했다는 뜻이다. 지속 시간, 실사용 빈도, 미실행 저장 결과는 브라우저 재현 범위에 포함하지 않는다.
