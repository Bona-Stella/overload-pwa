### 검증 중 문제와 해결

- 최초 Vite는 Console Ninja의 로컬 `127.0.0.1:3119` 연결이 sandbox의 EACCES로 차단됐다. 검증 서버 실행에 한정한 권한 허용 후 정상 실행했다. 프로젝트 설정/의존성은 바꾸지 않았다.
- 320px 데스크톱 viewport에서 기존 body 최소 너비와 일반 스크롤바가 겹쳐 가로 넘침이 발생했다. 프리뷰가 있을 때만 body 최소 너비를 해제하고 32개 조합을 다시 측정해 해결했다.
- 최종 확인 뒤 인증 만료 시 재인증 증명이 남는 경계를 자체 검토에서 발견해 무효화했고 회귀 테스트를 추가했다. 로그아웃 취소 시 지연된 로그아웃 의도도 해제한다.
- 신규 가상 가입 후 재로그인에서는 다시 가입을 요구하지 않도록 등록 상태를 보존하고 테스트했다.
- UI 자동화에서 비고유 버튼명/지원하지 않는 locator 옵션 때문에 일부 조작을 재관찰한 뒤 정확한 대상에 재실행했다. 앱 자체 오류는 없었다.
