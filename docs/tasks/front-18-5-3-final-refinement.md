| 실제 평균 심박수 | 완료 검토(N25)와 기록 정정(N28)의 선택 입력을 정수 20–300 BPM 휠로 바꿨다. 1 BPM 이동, 직접 입력, 공란 복원, 취소를 지원한다. 기존 거리·속도 직접 입력과 활동 시간 휠의 역할을 유지했다. |

속도·페이스 전환은 기존 `60 / 값`과 소수 여섯 자리 정책을 쓴다. 일반 속도 표시는 소수점 한 자리다. 페이스 휠은 `0:00`을 공란 옵션으로 사용하며, 기존 최소 `0:06`은 직접 입력으로 허용한다. 5초 격자의 첫 유효 옵션은 `0:10`이다. 페이스의 표시용 초를 API의 소수 분으로 환산하는 작업은 새 값을 명시적으로 선택할 때만 수행한다. 거리·속도·경사도·저항의 반올림은 루틴 편집의 일반 표시와 휠 시작 위치에만 적용된다. 경사도는 0–50, 저항 직접 입력은 1–100의 기존 계약을 사용한다. 운동 중 계획 편집은 5-3B의 표시와 입력을 사용한다.
