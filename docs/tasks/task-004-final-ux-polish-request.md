# Overload — Task 004 최종 보완: Reps Quick Input & Rest Countdown Warning

## 배경 및 목표

Task 004의 `task-004-progression-history-report.md`는 중량 변경 이력 및 `WeightInput`(±2.5kg)을 완료했다고 보고했습니다. 그러나 앞서 합의한 **세트별 반복 횟수 ±1 버튼**은 보고서에 구현 여부가 확인되지 않습니다. 또한 별도 합의한 **휴식 종료 임박 시 시각적 준비 신호**는 이번 보고서 범위에 들어 있지 않습니다.

이 작업은 두 항목의 현 상태를 먼저 확인하고, 누락된 부분만 구현해 **Task 004를 마무리**하는 최소 범위 보완입니다. 기존 데이터/핵심 운동 상태 전이를 변경하지 마세요.

## 선행 조사

1. 기존 `AGENTS.md`, `docs/product/requirements.md`, `docs/product/ui-ux.md` 및 최신 Task 004 보고서를 읽습니다.
2. 실제 소스에서 반복 횟수 ±1 입력과 휴식 종료 임박 UI가 이미 있는지 조사합니다. 구현되어 있다면 중복 구현하지 말고 테스트/브라우저 확인만 수행합니다.
3. 현재 `git status`, 기존 미커밋 변경과 사용자가 의도한 `vite.config.ts` `server.host: true`를 보호합니다. 서버 저장소는 수정하지 않습니다.

## A. 세트별 반복 횟수 빠른 입력

- 실제 운동 중 **각 본세트의 반복 횟수** 입력 UI를 `[ −1 ] [ 중앙 숫자 입력(회) ] [ +1 ]` 구조로 변경합니다.
- 중앙 숫자 영역을 누르면 iPhone에서 숫자 키패드가 나타나도록 적절한 `inputMode`와 input type을 사용합니다. 최소 16px 텍스트, 명확한 접근성 라벨과 적절한 터치 크기를 유지합니다.
- 좌우 버튼은 해당 세트 **초안 값만** ±1씩 조절합니다. 버튼을 눌렀다고 세트가 자동 완료되거나 휴식 타이머가 시작되어서는 안 됩니다.
- 완료 가능한 반복 횟수는 기존 정책을 따릅니다. **1 이상의 정수만 세트 완료 가능**, 목표 상한(예: 10회)을 넘는 횟수도 입력 가능합니다. 음수/0/소수/빈 값 완료는 차단합니다.
- 빈 값/편집 중 임시 값은 임의의 횟수로 자동 치환하지 않습니다. 버튼 처리 시 미완성 입력값·안전한 정수 범위를 방어합니다. 감소 버튼은 1회에서 비활성화합니다.
- 다른 세트의 초안을 건드리지 않고, 중간 세트 휴식, 마지막 세트 후 즉시 `다음 종목으로`, 전체 완료 후 수동 종료, 행 완료와 하단 완료의 동작 일치를 유지합니다.
- 저장/새로고침/이어하기 후 각 세트 초안과 실제 완료 값이 정확히 복원되어야 합니다. 완료 취소 및 수정 동작도 유지합니다.
- 375/390/430px 모바일 화면에서 오버플로·키보드·고정 CTA와의 충돌이 없도록 점검합니다. 현재 중량 `WeightInput`의 ±2.5kg UI와 디자인 언어를 맞춥니다.

## B. 휴식 종료 준비 신호

- **일반 본세트 사이의 휴식 카운트다운**에서만 남은 시간을 기준으로 시각적 표시를 변경합니다.
- 남은 11초 이상: 기존 디자인 유지.
- 남은 **10~6초**: 타이머 중심의 주황/노란 계열 강조와 `다음 세트 준비` 안내.
- 남은 **5~1초**: 타이머 부분에만 부드러운 강조 애니메이션(선택적으로 약한 pulse). 전체 화면 플래시/빠른 점멸 금지.
- 남은 0초: 기존 휴식 종료 로직과 문구/버튼을 그대로 사용하고, 경고 애니메이션이 지속되지 않도록 합니다.
- 색상에만 의존하지 않도록 텍스트도 제공합니다. `prefers-reduced-motion: reduce`에서는 애니메이션 없이 정적인 강조를 보여줍니다.
- 소리, 진동, 권한 요청, 잠금 화면 알림, Service Worker는 이번 범위에 포함하지 않습니다.
- 기존 타이머의 완료 예정 시각에서 **현재 남은 시간**을 파생해 표시합니다. 새로운 interval, 별도 저장 필드, 매초 localStorage 쓰기, 운동 기록이나 기준 판정 변경을 추가하지 않습니다.
- `+30초`로 10초 초과가 되면 일반 표시로 복귀하고, 수동 `휴식 종료`, 새로고침 복원, 탭 전환에서도 표시가 정확히 동작해야 합니다.
- 마지막 세트 완료 후 종목 이동 경과시간에는 휴식 경고가 나타나지 않아야 합니다. 모든 종목 완료 화면에도 나타나지 않습니다.

## 검증 조건

- 각 세트 `−1/+1` 반복 조작, 직접 입력/정정, 빈 값·1회·11회·소수·음수·큰 수 경계, 초안 저장/복원.
- 행 완료/하단 완료, 완료 취소, 일반 휴식과 마지막 세트 상태 전이, 원본 루틴/승인 중량/이력/기준 기록 보호.
- 타이머 11초→10초→5초→0초, +30초 복귀, 휴식 수동 종료, 재로드·이어하기, reduced-motion.
- 가능하면 실제 브라우저 DOM 상호작용으로 375/390/430px 화면과 고정 CTA/키보드 접근성을 점검하고, 실제 iPhone 실기기는 수행하지 않았으면 명확히 미검증으로 보고합니다.
- `npm test`, `npm run lint`, `tsc -b`, `npm run build`, `git diff --check` 실행. 유효한 회귀 테스트를 추가하며 기존 검사를 약화하지 않습니다.
