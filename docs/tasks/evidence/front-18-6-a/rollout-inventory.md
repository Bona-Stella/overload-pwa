# FRONT 18 6-A 사용처 대조

[6-A 구현 범위](../../front-18-6-a-dropdown-menu-foundation.md) · [6-1 기준 92개 위치](../front-18-6-1/selection-inventory.md)

아래 집계는 6-1의 번호를 유지한다. 동일 부품을 공유하는 화면은 기존 조사 단위로 각각 1회 센다. 버튼이 그대로인 화면에서도 공용 검색 목록 또는 가로 필터 스타일을 받은 경우 적용으로 표시한다. 업무 Dialog·수치·기간 등은 기능과 승인 규격을 유지한다. 전수 사용자 검수는 6-4에서 다시 대조한다.

요일별 루틴, 제조사, 부하 방식은 검색창 없는 TYPE 1이다. 운동 종목은 기존 TYPE 4의 검색·목록을 사용한다.

## 추가 검색 결과

`details/summary`, 자리 이동형 트리거, 클릭으로 열린 작은 목록, 액션 이름·삭제 콜백, 절대 위치 CSS, 가로 overflow를 함께 검색했다. 운영의 ⋯ 액션 팝오버 3곳은 모두 기준표의 UI009·013·064와 대응한다. 이들과 동등한 추가 운영 액션 팝오버는 **0개**다. 아래에서 동작이 비슷해 보이는 6개의 추가 구조를 확인했다.

| 화면·접근 경로 | 구현·동작 | 대조 및 적용 |
| --- | --- | --- |
| 앱 기본 탐색 → 접힌 현재 탭 | `AppShell` · 네 개 기본 탭을 하단에서 펼침 | 화면 이동 네비게이션과 포인터 보호, 기존 구조 사용 |
| 기록 → 운동 분석 메뉴 | `StatisticsPanel` · 네 개 분석 진입 카드가 항상 표시 | 페이지 내 탐색, 열린 팝오버 없음 |
| 루틴 편집 → 제거한 종목 복원 | `RoutineForm` · 기존 배치를 서버에서 읽고 인라인 복원 | UI031, 선택 목록과 초안 절차 유지 |
| 기록 → 복구 불가 항목 | `ClosedWorkout` · 상태 사유를 인라인으로 읽음 | UI069의 하위 정보, 사본 값 선택만 공통화 |
| 운동 진행 → 저장 상태 상세 | `WorkoutSaveLabel` · 복구 작업이 있는 업무 Dialog | 기존 Dialog와 재확인 흐름 사용 |
| 설정 → 앱 설치 및 오프라인 준비 | `PwaStatus` · 설치 안내가 펼쳐짐 | 읽기용 인라인 disclosure 사용 |

가로 overflow의 태그 대상은 홈 필터와 공용 SearchList의 웨이트·유산소·성장·운동 현황·전체 이력·카탈로그다. 수치 차트의 가로 스크롤과 기록 헤더의 정보 행은 기능 전용이다. 공통 Preview의 테스트 상태 native select와 과거 Demo의 두 유산소 select는 서비스 집계와 별도다.
