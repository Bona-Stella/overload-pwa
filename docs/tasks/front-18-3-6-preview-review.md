# FRONT 18 · 3-6 Preview 검수 안내

[PC Preview](http://127.0.0.1:4173/common-ui-preview.html?front18=1) · [같은 Wi-Fi에서 열기](http://192.168.0.3:4173/common-ui-preview.html?front18=1)

기존 `공통 UI Preview`에서도 `FRONT 18 안내·오류·복구 검수` 링크로 열 수 있다. 예시 상태는 탭 메모리에서 실행된다. `검수 분류로 돌아가기`로 다른 화면을 열거나 `저장 완료 · 정상 상태 초기화`로 운동 예시를 다시 열 수 있다. 조회 실패 단추는 다음 조회 한 번을 실패시키는 경우가 많으므로, 화면 자체의 재조회 버튼으로 복구를 확인한다. 예약 단추는 표시 대상이 되는 실제 버튼을 누를 때 적용된다.

검수 진입·상태 전환 버튼은 운동 46개, 일반 페이지 45개, 기록 정정·삭제·복구 8개, 계정·설치 25개다. 돌아가기 및 검수 도구 열기 단추는 집계에서 제외했다.

| 반복 횟수 범위 오류 | 반복 횟수는 1~2147483647 범위의 정수를 입력해 주세요. | `1세트 완료` |

| 유산소 활동 시간 없음·시간 정정 범위 오류 | 실제 활동 시간은 1ms~24시간이어야 합니다. 타이머와 정정값을 확인해 주세요. / 정정한 운동 시간을 확인해 주세요. | `유산소 기록 확정` |
| 유산소 거리·속도·심박수 | 직접 입력 거리는 0.001~1000 km여야 합니다. / 소수점 여섯 자리 이내의 0 이상 값을 입력해 주세요. / 평균 심박수는 20~300 BPM을 입력해 주세요. | 거리·속도·심박수 범위 예시에서 `유산소 기록 확정` |
| 실측 속도만 입력 | 현재 서버는 평균 속도만 저장할 수 없습니다. 실제 거리를 입력하거나 평균 속도를 비워 주세요. | `유산소 기록 확정` |
| 예상 거리와 수정 속도 | 수정한 평균 속도를 저장하려면 실제 거리를 입력해 주세요. | `유산소 기록 확정` |
| 계산 거리 불일치 | 현재 시간·속도로 계산 거리를 저장할 수 없습니다. 실제 거리를 입력하거나 거리와 속도를 비워 주세요. | `유산소 기록 확정` |
| 거리·속도를 지원하지 않는 종목 | 거리와 속도는 러닝머신·자전거·야외 운동에만 입력할 수 있습니다. | `유산소 기록 확정` |
| 다음 완료·취소·종목 이동 실패 예약 | 이 기기에 저장하지 못했습니다. 저장소 설정과 여유 공간을 확인한 뒤 다시 시도해 주세요. | 값을 확정한 세트 완료나 종목 이동은 Toast. 기존 Dialog에서 실행한 취소·수정은 해당 Dialog 안에 표시한다. |
| 화면 이동 전 초안 저장 실패 | 입력 초안을 저장하지 못해 화면 이동을 보류했습니다. 운동 원본과 입력을 유지합니다. | 초안과 상단 저장 상태 상세를 확인한다. |
| 종료 시각이 마지막 수행보다 이름 | 기기 시각과 마지막 수행 시각을 확인해 주세요. 종료 시각을 자동 보정하지 않습니다. | `운동 종료 및 요약` |

Toast는 자동 종료와 `알림 닫기`를 지원한다. 예를 들어 연속으로 `1세트 완료`를 누르거나, 5초 지연 저장 중에 완료를 누르면 중복 표시와 저장 완료 전후의 독립 동작을 검수할 수 있다.

## 일반 페이지와 운동 예외 상태

| 검수 분류 | 전환 범위 및 사용자 조작 |
| --- | --- |
| 홈 로딩·운동 시작 | 정상, 최초 로딩, 조회 지연, 기존 데이터 재조회 실패, 운동 시작 실패, 시작 결과 미확인. 미확인일 때 `기존 시작 요청 다시 확인` |
| 루틴 조회 | 최초 목록 로딩, 종목 상세 지연, 빈 목록, 기존/미보유 데이터 조회 실패, 쓰기 오류와 회복. 정상 루틴 화면에 `ROUTINES`·`다시 조회` 상단 영역이 빠진 상태 |
| 주간 일정·계획 분석 | 정상, 일정 조회 지연, 기존/미보유 일정 오류, 쓰기 차단, 저장 충돌·실패, 목록과 개별 편집, 최신 구성 다시 열기, 계획 분석 최초·재조회 오류와 복구 |
| 최근 운동·전체 이력 | 최초 로딩, 빈 기록, 기존 기록을 유지하는 재조회, 기록 조회 실패와 복구 |
| 성장 추적 | 검색 지연·오류·복구. 종목 선택 후 기간 변경과 이전 그래프 유지, 기간·배치 조회 오류와 재조회 |
| 운동 종목 보기·설정 메인 | `표준 운동`, `조회 전용`, `운동 이름과 별칭으로 검색`. 실제 검색과 상세, 휴식 타이머 알림의 `휴식 테스트` 설정 |

| 운동 내부 처리 | 초안 또는 장치 저장 실패, 서버 저장 거절, 일시 전송 오류 및 자동 재시도, 지연 응답, 단순 조회 및 잠정 중량 검토 실패, 재연결. 장치에 남은 입력과 실제 복구 Dialog 확인 |

## 구현과 검증 경계

운동은 실제 `LocalWorkoutScreen`, `LocalWorkoutView`, `WorkoutFrame`, `WorkoutSaveLabel`, `LocalWorkoutController`와 동기화기를 실행한다. 일반 페이지는 `WorkspaceView`, `HomePanel`, `RecordFeed`, `GrowthPanel`, `RestSettings`, `AccountSettings`, `ClosedWorkout` 및 기존 CSS·테마를 사용한다. 메모리에서 네트워크 응답, 장치 쓰기, 락, 계정 상태를 제공한다. 4173의 검수 HTML은 연결과 폼 전송을 차단한다. 운영 빌드와 PWA 사전 캐시에서 이 HTML 및 검수 번들을 제외한다.

실제 OAuth 제공자 이동, 이메일 발송, 실기기 설치·캐시 업데이트, 실제 저장소의 접근 거부·용량 고갈은 이 화면에서 수행하지 않는다. 결과 화면에는 합성 응답을 공급한다. 이미 끝난 세트를 동시에 완료하거나 입력 직후 편집권을 잃는 등 작업 대기열 내부의 경합 방지 분기는 실제 UI의 잠금으로 해당 버튼을 보통 누를 수 없으므로 집중 회귀 테스트에서 함께 확인한다. 원본 세션에 의존하는 네트워크·권한 경계는 합성 스냅샷을 사용한다.
