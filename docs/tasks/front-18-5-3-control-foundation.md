## 숫자 휠과 데이터 보호

- 최초 중심 주변만 렌더링하고 앞뒤 가장자리에 도달하면 20개씩 추가·교체한다. 앞에서 삽입 또는 제거된 행만큼 스크롤 좌표를 보정하며 한 번에 최대 61개 옵션을 유지한다. 방향키는 중앙 선택과 실제 포커스를 같은 버튼으로 이동시키고, 휠 옵션의 Tab 정지점은 선택된 버튼 하나다.
- PLATE·STACK 2.5kg, 기타 1kg는 같은 필드의 바깥 버튼과 휠에 공유된다. 목표 거리·속도는 고정 소수점 연산으로 0.1씩 이동한다. 기존 52.3kg·5.123km는 열기나 취소로 정규화하지 않는다. 값 선택·확인은 해당 입력의 초안에만 반영된다.
- 거리·속도는 선택 입력을 공란으로 되돌릴 수 있다. 0을 공란으로 변환하지 않으며 각 필드의 기존 유효 범위를 검사한다. 유산소 목표 시간은 종전 분 소수 입력 경로와 초 저장 계약, 24시간 한계를 유지한다. 기록 정정은 분 또는 시를 편집해도 기존 소수 초를 보존한다.
- 사용자가 반복의 같은 제안값을 확인하면 기존과 같이 확정된다. 다른 휠은 조작 없이 확인해도 기존값을 유지한다. 운동 승인, 데이터 버전, 네트워크 저장, 오프라인 스냅샷과 중복 보호의 진입점은 기존 흐름을 사용한다.
- 휴식 설정 계약은 고정된 1~10회·11~12회·13회 이상 세 필드를 읽고 쓴다. 네 번째 구간을 조회하거나 저장하는 계약과 자동 연결 규칙은 현행 API에 없다. Preview의 네 열은 읽기 전용 배치이며, 실제 계정은 기존 3개 구간의 초 값만 편집한다. 해당 계약에 4개 초과 저장 데이터가 들어오는 경로를 확인하지 못했다. [휴식 설정 API](../../../overload-server/docs/api/workout-online-write.md)
