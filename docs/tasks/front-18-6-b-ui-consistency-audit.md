## 6-C 범위 논의에 필요한 결정

- **기능형 Dialog의 바깥 모서리와 기본 여백.** 현재 18px·23px·제목 아래 22px를 업무별로 유지할지, 공통 기본값을 정할지가 남아 있다. 내부 일반 카드의 5px 복원은 기존 규격으로 진행할 수 있다. 너비·제목 정렬·스크롤·고정 액션은 업무 요구에 따른다.
- **유산소 실제값의 정보 순서와 편집 진입.** 완료 검토의 거리·속도·BPM·출처 안내의 순서, 읽기 화면의 표시 자릿수·단위, 정정에서 원본 시간과 정정 여부를 보존하며 시간행 표현을 어느 정도 공유할지 논의가 필요하다. 기존 저장 정밀도·직접 입력·BPM 휠의 단위는 확정 기준이다.

## 검증 범위와 한계

- **실제 4174**는 Mac Chrome에서 홈 셸과 56px 트리거, 루틴 탭과 일정 편집, 월요일 선택의 검색 입력 0개·현재 옵션 1개, 기록 분석 진입, 설정 목록을 확인했다. 인증과 읽기만 허용하고 START·저장·승인·삭제 등 제품 데이터 쓰기는 차단했다.
- **기존 4174 합성 Preview**는 운동 순서·웨이트 추가/교체·유산소 추가/계획 편집·중량 변경·웨이트/유산소 정정·복구와 유산소 완료 검토를 393px에서 확인했다. 순서와 웨이트 정정은 320px의 좁은 표본, 실제 셸은 1280px에서 520px 폭을 확인했다. 운영의 미표본 하위 상태는 소스로 대조했다.
- 실제 운동 시작 이후의 쓰기, 승인·복구 저장과 실패, 6-1의 짧은 키보드 화면은 브라우저에서 재검증하지 않았다. 기기 인계·네이티브 설치·iPhone Safari·설치형 PWA·VoiceOver·실기기 가상 키보드·보호 GIF는 미확인이다.
- 근거는 소스·DOM·계산된 CSS·조작 결과다. 기존 4174를 재사용했고 전체 회귀와 빌드는 실행하지 않았다. PWA 및 Backend 작업 트리를 확인했다. 산출물은 이 보고서와 전체 현황표 두 문서다.
