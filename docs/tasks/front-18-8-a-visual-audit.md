# FRONT 18 · 8-A 타이포그래피·아이콘·세부 간격 전수조사

2026-11-28 · FRONT 18 7-E 기준 `6fe66fb` · 8-B 논의 자료

## 결과 요약

웨이트 완료 시 **표 ‘이번 기록’의 반복 횟수**가 16px 숫자 휠 버튼에서 12px 완료 텍스트로 바뀌었다. 행은 4px 줄고, 별도 자동 스크롤이 뷰포트를 이동했다. 세트 카드 상단 카운터는 다섯 폭에서 13px/700을 유지했다. [웨이트 완료 원인](#웨이트-완료-시-글자와-위치가-바뀌는-원인)

Chrome에서 대표 **화면·상태 40개**를 다섯 화면 폭으로 확인했다. 운영 진입점에서 연결된 **73개 TSX 파일의 텍스트·공통 조작 선언 1,485곳**, **42개 CSS 파일의 관련 선택자 1,094개**를 추적했다. 시각 규칙 955개에는 타이포그래피·색·줄바꿈 선언이 있다. 아이콘은 별도 태그에 반복된 도형까지 포함해 **운영 인라인 SVG 90개 구현 변형**이다. 전수 수치는 소스의 선언 위치이며 화면에 동시에 나타나는 인스턴스 수는 아니다. 동일한 SVG 경로를 공유할 수 있는 9개 도형군에서 중복 정의 10개를 찾았다. 문자·CSS 아이콘과 자산은 인벤토리에서 찾을 수 있다. [시각 인벤토리](front-18-8-a-visual-inventory.md)

18px 메인 제목과 22px 하위 제목을 적용할 수 있다. 메인 탭은 기존 제목 역할부터 확인해야 하고, 고정 3열 타이머·세트 표·긴 값은 내부 배치를 함께 검토해야 한다. 기존 화면의 정보 순서와 승인된 카드·조작 외곽을 유지하면서 적용할 수 있는 범위와 추가 결정이 필요한 범위를 아래에 기록했다.

- 착수 시 PWA `main`은 `origin/main`보다 2개 커밋 앞섰고 작업 트리는 깨끗했다. 7-C `ec6f9ca`, 7-E `6fe66fb` 및 7-E의 전체 회귀 745/752, 관련 파일 재실행 통과, 최종 집중 14/14 기록을 확인했다. 전체 회귀의 최종 재실행 기록은 없다. 형제 서버는 `5a12b1c`의 깨끗한 `main`이었다. [Frontend 현황](../engineering/frontend.md#front18-stage7)

### 실제 글꼴과 숫자 폭

`index.css`의 시스템 스택은 `-apple-system, BlinkMacSystemFont, 'Segoe UI', 'Noto Sans KR', sans-serif`다. 운영 진입점 스타일과 HTML에 폰트 파일·`@font-face`·웹폰트 preload는 없다. HTML의 preload는 워드마크 이미지용이다. `font-synthesis: none`이며 루트에 `tabular-nums`가 있다. Chrome의 혼합 제목에서 로컬 Apple SD Gothic Neo ExtraBold와 .SF NS를 확인했다. 같은 ‘운동 01234’를 16px로 투입하고 CSS 굵기별 실제 폰트를 조회했다. 이 Mac의 한글은 400 Regular, 500 Medium, 550·600 SemiBold, 650·700 Bold, 750·800 ExtraBold, 850·900 Heavy였다. 숫자는 .SF NS로 표시됐다. 요청값과 실제 글리프의 굵기 매핑은 시스템 글꼴 및 한글 대체 글꼴에 의존한다. iPhone/Windows 렌더링은 미계측이다. 같은 웨이트에서 고정폭 숫자는 자릿수 **내용** 변경을 안정화하지만 자릿수 **증가**, 상태에 붙는 ‘완료’ 및 단위에는 고정 폭을 제공하지 않는다. ## SVG 중앙 관리 제안

기존 `FeedbackIcon`의 경로 정의를 출발점으로 삼는다. 단일 SVG 렌더러가 의미 이름, 기본 크기, viewBox와 선 굵기, 장식 숨김 또는 접근 가능한 라벨을 받도록 한다. 테마는 `currentColor`로 전달한다. 공통 헤더·탭·설정·계정·일정의 동일 path부터 원본과 조작 영역을 유지한 채 공유할 수 있다. 예를 들어 `chevron-left`는 페이지 뒤로가기와 달력 이전이 같은 경로여도 각각의 버튼 크기와 접근성 이름을 호출부가 제공한다.

기본은 24×24 viewBox에 선 굵기 2, 크기는 12px 보조·16px 정보·20px 조작·24px 내비게이션·32px 특별 안내다. 기존 세부 viewBox가 16 또는 20이면 2를 그대로 이식했을 때 상대 선 굵기가 바뀐다. 초기 중앙화에서는 원래 viewBox·path·선과 상태색·hover/회전을 기록하여 유지하고 8-B에서 시각 통합을 승인한다. 활성 탭 채움·두꺼운 표시, 운동 저장 10px, 메시지형 Dialog 24px, 검색 18px/42px 조작, 디로딩 달 및 운동 원본 이미지는 각각 예외를 검토한다.

운영 코드에는 아이콘 전용 라이브러리가 없으며 기존 경로가 재사용의 출발점이다. 원본 path는 파일/기능으로 나누고 호출부에서 실제 사용하는 경로 모듈을 import하면 전체 아이콘 레지스트리의 일괄 포함을 피할 수 있다. 기존 SVG와 같은 렌더링 노드 수를 목표로 하고 버튼·상태 레이블을 추가 래퍼로 감싸지 않는다. 이후 빌드 검증 시 청크 증분과 탭/저장 상태의 DOM 변경을 확인한다. 기존 공통 UI Preview에는 이름·사용처·지원 크기와 현재/승인 예외 도형, Onyx/디로딩, 상태 애니메이션·모션 감소, 그림과 독립 조작 폭을 볼 수 있는 카탈로그를 둘 수 있다. ## 검증 경계

전용 계정 인증 이후 실제 Spring 화면·START·스냅샷, 실기기 iPhone Safari·설치형 PWA, 보존 DB, 모든 최대값 조합과 모든 브라우저의 글꼴 매핑은 이번 조사에서 검증하지 않았다. 토글·알림·차트·미디어의 모든 렌더링 분기는 소스 위치를 인벤토리에 남겼다. 설명용 DOM 값과 보고서 내 표만 사용했다. 문서 diff·Markdown·경로 링크를 검사했으며 제품 코드·공식 문서·서버·스키마에는 변경을 적용하지 않았다. 전체 회귀 및 빌드는 실행 범위에서 제외했다. 일회용 Chrome과 통계 fixture를 종료했다. 기존 4174 게이트웨이는 검수용으로 계속 실행 중이다.
