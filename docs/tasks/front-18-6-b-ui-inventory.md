# FRONT 18 — 6-B 전체 UI 현황표

2026-11-27 · PWA `5191a78` · [통합 분석 보고서](front-18-6-b-ui-consistency-audit.md)

운영 화면·하위 흐름 **43개**, 고유 조사 행 **177개**다. 화면은 01~43으로 표시한다. 공통 행은 별도 화면으로 세지 않는다. 기능형 작업과 그 내부 선택은 서로 다른 기준으로 조사하며 예를 들어 웨이트 검색 모달의 작업 구조는 F004, 첫 목록 표시 누락은 UI073·074에 기록했다. 같은 소스 문제를 공유하는 경우 조치 수로 중복 합산하지 않는다. 데이터에 따라 반복되는 카드·세트는 슬롯 단위, 월~일은 독립 입력 일곱 건이다.

5단계의 402개 개별 조작과 4단계의 80개 카드 표본은 화면·역할 기준으로 연결했다. 버튼마다 같은 기준을 반복 기입하는 방식은 생략했다. 선택은 6-1의 92개 번호를 모두 유지하고 현행 코드로 다시 확인했다. [4단계 카드 적용표](front-18-4-5-card-final-review.md#최종-사용처-적용표) · [5-4 개별 조작 조사](front-18-5-4-control-rollout.md#사용처-대조) · [6-A 적용 대조](evidence/front-18-6-a/rollout-inventory.md)

분류는 대표 상태 한 개를 사용한다. A는 현행 소스 기준이며 모든 폭에서 실측했다는 뜻이 아니다. 제품 실행과 합성 Preview의 확인 범위는 통합 보고서에 기록했다. 별도 승인 근거가 없으면 잠정 분류로 표시하고, 미확인 상태는 구현 완료로 간주하지 않는다.
